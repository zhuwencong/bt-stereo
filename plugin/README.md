# 双音箱左右声道（DSH 插件）

在 Windows 上把两只独立音箱（两只蓝牙，或一只蓝牙 + 一只有线）配置成一对左右声道。
本插件提供**安装、配置与排障向导**，并指向开源工具 [bt-stereo](https://github.com/zhuwencong/bt-stereo)。

## 安装

在市场里点「安装」，或在客户端执行 `dsh plugin install dsh-plugin-bt-stereo`。

## 使用

客户端里执行命令：

```
bt-stereo:setup
```

会返回完整流程：前提检查 → 安装（便携版 / 源码）→ 蓝牙体检 → 配置左右声道 →
延迟对齐 → 六类常见故障的处理办法。

直接对模型说「帮我把两个音箱配成左右声道」也可以，模型会按同一套流程引导你。

## 说明

- 本插件不含音频代码，真正的声道拆分由 bt-stereo 完成（Windows 桌面程序，MIT 协议）。
- 不修改系统设置、不安装驱动；bt-stereo 运行时会临时切换系统默认播放设备，停止即恢复。
