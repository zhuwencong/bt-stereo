# 双音箱左右声道

> 技能标识：`dual-speaker-stereo` · 把两只音箱拆成左右声道的安装与排障向导

Windows 自身没有"把两只独立音箱组成一对左右声道"的能力。本技能指导你用开源工具
**bt-stereo**（WASAPI 回环捕获 + 双路输出）帮用户完成配置，并处理延迟、卡顿、单边无声等常见问题。

- 仓库：<https://github.com/zhuwencong/bt-stereo>
- 国内镜像：<https://gitee.com/xingchencong/bt-stereo>
- 便携版（免装 Python）：<https://github.com/zhuwencong/bt-stereo/releases/latest>

## 适用场景

- 用户有两只音箱（两只蓝牙，或一只蓝牙 + 一只有线），想让它们分别承担左右声道
- 用户已经装了类似工具，但出现"只有一只响""声音有回声""播放卡顿"
- 用户想确认自己的电脑蓝牙能不能同时连两只音箱

## 执行工作流与检查清单

1. **确认前提（先问再动手）**
   - 必须是 Windows 10/11，macOS / Linux 不支持（依赖 WASAPI）。
   - 两只音箱必须同时处于"已连接"状态；只在"已配对"列表里不算。
   - 询问用户是"两只蓝牙"还是"一只蓝牙 + 一只有线"，这决定后续延迟补偿策略。

2. **选安装方式**
   - 不想装 Python → 下载便携版 zip，解压双击 `bt-stereo.exe`（推荐给普通用户）。
   - 愿意折腾 → `git clone` 仓库，`python -m pip install numpy comtypes`，双击 `启动.bat`。

3. **先体检，再配置**
   ```bat
   python -m bt_stereo --cli doctor
   ```
   这是只读检查。看最后的「结论」行：
   - "2 只蓝牙音箱同时在线" → 环境就绪
   - "只连上了 1 只" → 让用户去 设置 → 蓝牙和设备 把另一只点「连接」，等 5 秒再跑一次
   - "蓝牙适配器没有正常工作" → 让用户去设备管理器检查驱动，**不要自己动驱动**

4. **配置与启动**
   - 界面里只需选两件事：左声道音箱、右声道音箱。
   - 音源保持默认：程序会在点「开始」时自动把系统默认播放设备切到音源端点，停止时恢复，用户不需要手动改声音设置。
   - 命令行等价写法：
     ```bat
     python -m bt_stereo --cli run --left "音箱A" --right "音箱B" --source "扬声器 (虚拟声卡)"
     ```

5. **延迟对齐（有线 + 蓝牙组合必做）**
   - 蓝牙链路通常比有线慢 150~250ms，因此**慢的那一侧不需要补偿，快的那一侧要加延迟**。
   - 有线 + 蓝牙：给有线那侧填 200ms 起步，再按听感微调。
   - 两只都是蓝牙：通常留 0 即可，仍不同步时给慢的加 20~80ms。
   - 判断方法：放有人声的歌，听是否像"回声"。

6. **验收**
   - 界面「试音」：左 440Hz、右 660Hz 各响一次，两只都响即成功。
   - 命令行自检：`python -m bt_stereo --cli test`
   - 若仍只有一个声道有声音，进入故障树。

## 故障树（按顺序排查，不要跳步）

| 症状 | 先查 | 处理 |
| --- | --- | --- |
| 某只音箱完全没声 | 界面点「蓝牙检测」，看该端点是否在"当前播放端点"里 | 不在 → 重新连接该音箱；在 → 点「试音」判断是软件还是箱子本身 |
| 只有一只响，另一只在端点列表里 | 状态栏是否显示"重连中/离线" | 等自动重连；不行就 停止 → 开始 |
| 声音断续、卡顿 | 状态栏欠载计数是否增长 | 关闭占带宽的下载/投屏；把音箱靠近电脑、远离路由器；两只蓝牙同时用易受 2.4GHz 干扰，建议改一只有线 |
| 有回声、左右不同步 | 延迟补偿是否为 0 | 给"听起来慢"的那侧加延迟，20ms 一档往上试 |
| 系统其它声音也变了 | 程序自动切换了默认播放设备 | 点「停止」即恢复；这是设计行为 |
| 提示音源没有声音 | 音乐实际播到了哪个设备 | 程序会自动切默认设备，但若播放器锁定过输出设备，需在播放器里改回"默认设备" |

## 输出格式规范与边界条件

- 回答用户时先给结论（能配 / 不能配 / 卡在哪一步），再给具体操作，命令用代码块。
- 询问硬件信息时一次只问一组（先问音箱数量和连接方式，再问型号）。
- **边界：**
  - 不卸载、不重装用户的蓝牙驱动或设备。
  - 不写蓝牙相关注册表（`BTHPORT\Parameters\Devices` 只读是有意为之）。
  - 不擅自设置开机自启、不改动用户其它音频软件。
  - 不承诺"一定能双连"：能否同时连两只蓝牙取决于适配器是否支持两条 A2DP 链路，
    Intel AX200/AX201/AX210 一般可以，部分 Realtek 模块只允许一条；这种情况建议换
    USB 蓝牙 5.3 适配器，或改用音箱自带的 TWS 配对（仅同型号音箱支持）。
- 遇到本技能未覆盖的现象，建议用户运行 `doctor` 并把输出贴到仓库 Issue。
